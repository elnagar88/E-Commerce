# FreshCart 🛒

A modern E-commerce application built with Next.js, TypeScript, Tailwind CSS, and Shadcn UI.

## 🔗 Live Demo
[View FreshCart]([https://your-vercel-link.vercel.app](https://e-commerce-ruddy-kappa-ns7bc6njyh.vercel.app/))

## 🛠️ Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- Shadcn UI
- NextAuth.js
- React Hook Form
- Zod

## ✨ Features
- User Authentication
- Product Browsing
- Shopping Cart
- Wishlist
- Product Reviews
- Checkout
- Responsive Design
